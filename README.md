# Ashoka Quiz Portal

A modern online quiz and assessment platform for **Ashoka Women’s Engineering College (Autonomous)**.

## Planned platform
- Student quiz access through QR code or shareable link
- Faculty quiz creation and publishing
- 25–30 MCQ assessments
- Automatic timer and evaluation
- Ranking by marks, then completion time
- Student, Faculty, HOD and Admin dashboards
- Department-wise performance reports
- Supabase-backed authentication and data storage
- Responsive mobile-first quiz experience

## Current build
The repository currently contains the polished responsive landing page and initial Student/Faculty portal interactions. The next development stage connects authentication, quiz data, QR generation, submissions, ranking and reports.
